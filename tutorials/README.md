## What this tutorial does that a plain inference demo does not

**It keeps the evidence honest about references.** Every number is computed against a sharp original that the sample itself degraded, on test photographs that never contribute training crops. Three baselines frame the result: the blurred input (the floor), unsharp masking (blind, tuned on training pairs only), and Wiener deconvolution given the true kernel (an oracle no real deblurrer has). The real camera-motion photograph in Section 8 has no reference, so it gets no PSNR, only a labelled sharpness proxy.

**It treats the checkpoint as code.** The upstream `.pth` is a pickle. It is accepted only at the pinned size and SHA-256, unpickled once with `weights_only=True`, converted to safetensors with an exact output check, and never unpickled again; the artifact the notebook exports is safetensors with a manifest that is verified before loading.

## Conformance notes

- **Standalone carrier (ST1–ST8, SRC4, SRC12):** no clone, repository install or repository import in the kernel. The carrier writes every carried file into a fresh run directory and verifies it against `CARRIED_HASHES`; `load_architecture` checks the three upstream files once more against their upstream digests before executing them.
- **Isolated environment (RUN1, RUN10, ENV1, ENV2, ENV6; §25.13):** no cell pip-installs into the kernel; kernel cells import only the standard library, `IPython.display` and (for the BYOD upload) `google.colab`. The install cell verifies the `uv` 0.12.15 wheel by size and SHA-256, creates a managed CPython 3.12.12 environment, installs the carried lock with `uv pip install --require-hashes --only-binary :all:`, strips Hugging Face tokens and `PYTHONPATH`, sets `MPLBACKEND=Agg`, and prints the environment's versions. `run_stage` re-raises a failed stage's own exception type and message.
- **Model acquisition (MOD1–MOD9):** identity in `pipeline.py` and the carried manifest must agree; the checkpoint is accepted only at the pinned size and SHA-256 from either mirror, with no fallback to other bytes; `weights_only=True`; strict state-dict load; safetensors conversion with an exact output comparison. The mirror is addressed by branch, and its identity is the SHA-256; see `../docs/WEIGHTS.md` for the residual trust gap.
- **Stages (§4.1), one process each:** `weights` → `prepare` (sample, validation, refusal probes, split by photograph, digest) → `baseline` (identity, unsharp and oracle Wiener tuned on train; pretrained) → `adapt` (always from the verified base; bounded fine-tuning; in-memory reference outputs; artifact export) → `evaluate` (fresh process, artifact verified before loading; paired comparison) → `reload` (second fresh process; output equivalence within 1e-5; two new images; `result.json`) → optional `activity` (from the base, scope changed, everything else fixed) and `byod`.
- **BYOD (DAT10–DAT19):** `USE_BYOD = False` by default; `BYOD_PATH` bypasses the upload dialog (EXE2). Paired data runs validate → split → baselines → adapt → evaluate → export → reload → infer and writes `byod_result.json`, `byod_test_metrics.csv`, restored PNGs and its own artifact; unpaired data runs validate → infer with no metric.
- `tools/validate_release_assets.py` performs source validation only and is not execution evidence (REL8).
